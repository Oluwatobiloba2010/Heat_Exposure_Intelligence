HOW TO INSTALL
1. Close RStudio or ensure no project scripts are running.
2. Make a full backup of the current Heat_Exposure_Intelligence project folder.
3. Extract this ZIP into the existing project root, preserving folders. Merge and replace the supplied R/ and outputs/ folders.
4. Do not merge this patch with the earlier Renumbering_Patch ZIP. Discard that earlier patch; this ZIP supersedes it.
5. Open the project in RStudio and run the included static validation script: VALIDATE_RENUMBERING.R from the project root.
6. If validation passes, continue with Script 11 (project-wide QA and consolidation). Do not rerun Scripts 00-10 merely to rename files.
